## 📊 COMO FUNCIONA O SISTEMA DE ORÇAMENTO

O Guia do Aventureiro possui um sistema completo de gerenciamento de orçamento para suas viagens, permitindo planejar e controlar gastos de forma detalhada.

---

## 🎯 CÁLCULO AUTOMÁTICO DO ORÇAMENTO ESTIMADO

Quando você gera um roteiro com a IA, o sistema calcula automaticamente um **orçamento estimado** baseado em:

### **Fórmula Base:**
```
Orçamento Total = Custo Diário × Número de Dias
```

## 📱 CONTROLE DE GASTOS REAIS

### **Como Adicionar Gastos:**

1. Entre no detalhe do roteiro
2. Toque em "Gerenciar Orçamento" ou "Adicionar Gasto"
3. Preencha os dados:
   - **Categoria:** Hospedagem, Alimentação, Transporte, Atrações, Compras ou Outro
   - **Descrição:** Ex: "Hotel dia 1-3", "Jantar Restaurante X"
   - **Valor:** R$ 450,00
   - **Data:** (opcional) quando o gasto foi feito

### **Categorias de Gastos:**

| Ícone | Categoria | Exemplos |
|-------|-----------|----------|
| 🏨 | Hospedagem | Hotel, Airbnb, pousada, albergue |
| 🍽️ | Alimentação | Restaurantes, supermercado, lanchonetes |
| 🚗 | Transporte | Uber, passagens aéreas, ônibus, aluguel de carro |
| 🎭 | Atrações | Ingressos, tours, museus, shows |
| 🛍️ | Compras | Souvenirs, roupas, presentes |
| 💳 | Outro | Despesas diversas |

## 🎯 DICAS PARA CONTROLAR O ORÇAMENTO

### **Durante o Planejamento:**
1. ✅ Escolha o nível de orçamento realista para seu perfil
2. ✅ Pesquise preços reais de hospedagem e atrações
3. ✅ Adicione 10-20% de margem para imprevistos
4. ✅ Compare os valores estimados com reviews de outros viajantes

### **Durante a Viagem:**
1. ✅ Adicione cada gasto imediatamente após gastá-lo
2. ✅ Verifique o orçamento diariamente
3. ✅ Se aproximar de 80%, reduza gastos opcionais
4. ✅ Guarde recibos para conferência posterior

### **Após a Viagem:**
1. ✅ Revise todos os gastos
2. ✅ Use os dados para planejar a próxima viagem
3. ✅ Compartilhe seu roteiro com orçamento real para ajudar outros
